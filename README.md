# useless_notes

> 一個專門收藏廢筆記嘅地方。冇用、冇系統、冇保證。

呢個 repo 入面全部嘢都係廢嘅：考完就唔記得、背完都用唔著、排版靚都只係一堆數碼雜物。
唯一嘅價值係「唔想 delete」——所以塞埋一堆，眼不見為淨。

## 檔案點排

```
notes/<科目>/<檔名>.pdf
```

## 命名規則

`<考試>_<科目>_<主題>_<可選補充>.pdf`

- 英文檔名 + 底線，唔用空白、括號、`(1)` 呢啲重複下載後綴。
- 中文標題只留喺 PDF 內文同上面個表，唔入檔名（免得各種工具亂碼）。

## 免責

- 內容唔保證正確，亦唔保證有用；錯咗唔會更新。
- 冇 version 紀律、冇 review、冇 changelog。commit message 求其打。
- Clone 咗唔會令你考試高分，只會令你多一個唔會開嘅 PDF。

## 想加嘢？

新筆記一律掉落 `notes/<科目>/`，再喺上面個表加一行。冇其他規矩。
